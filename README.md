# 🐦 Bird Feeder Bot (Классификатор птиц)

> **Умный Telegram-бот**, который определяет вид птицы по фотографии с помощью нейросети и подсказывает, чем её можно безопасно покормить! 🍞✨

---

## 🚀 Особенности проекта

* 📸 **Распознавание по фото:** Бот принимает изображение и определяет птицу с указанием процента уверенности модели.
* 🥗 **Забота о природе:** Для каждого подтипа выдаются рекомендации по правильному и безопасному рациону питания птицы, что предотвратит случайное отравление существа.
* 🧹 **Авто-чистка:** Все временные файлы загруженных фотографий автоматически удаляются с сервера после обработки, данные не передаются третьим лицам.
* 🎯 **4 поддерживаемых вида:**
  * Голуби
  * Синицы
  * Вороны
  * Пеликаны

---

## 🛠️ Запуск

* **Создание токена:** Создайте токин для своего бота в боте BotFather, после чего вставьте его(токен) в константу TOKEN в файле config.py. Бот готов к использованию!
